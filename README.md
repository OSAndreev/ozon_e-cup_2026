# E-CUP 2026, кейс 2 «Контроль качества» — решение EXP-188

Классификация карточек маркетплейса на «бан» / «не бан» в категориях БАД и
Легковоспламеняющиеся. Метрика — среднее бинарных F1 позитивного класса по двум категориям.

**Публичный скор: 0.836186457705445**

## Состав

```
submit/                        содержимое отправленного архива
  run.py                       точка входа контейнера
  train_data.csv               трейн, предоставленный организаторами
  params.json                  коэффициенты стека ЛВ
  prompts.py                   промпты LLM-стадий
  fewshot_submit.json          демонстрации для few-shot (отобраны из трейна)
  lv_groups.json               группы товаров ЛВ (из трейна)
  metadata.json                образ и точка входа
artifacts/
  EXP-188_nbsub_submission.zip отправленный архив целиком
```

Файлы в `submit/` побайтово совпадают с содержимым архива.

## Подход

**БАД.** TF-IDF по склейке названия и описания: словесные 1–2-граммы (min_df=2, 200k)
и символьные char_wb 3–5-граммы (min_df=3, 300k), NB-взвешивание признаков,
логистическая регрессия (liblinear, C=4.0, class_weight="balanced"). Вердикт — отбор
верхней доли по убыванию вероятности.

**Легковоспламеняющиеся.** Стек из шести каналов с фиксированными коэффициентами
(`params.json`): два текстовых (полный текст и извлечённые атрибутные поля) и четыре
LLM-канала — few-shot и retrieval-few-shot к `gemma-4-E4B-it` и `Qwen3.5-4B`. Вердикт —
плагин-правило максимизации ожидаемого F1 по вероятностям модели. Поверх — оверрайд по
точному ключу name+description с большинством меток дублей в трейне.

Обе модели обучаются внутри контейнера на каждом запуске; сохранённых весов нет.

## Запуск

```bash
python submit/run.py --test_data_path <test.csv> --output_path <out.csv>
```

Образ `odsai/ecup26-quality-baseline:1.0`, модели берутся из `/shared_models`.
При отсутствии GPU контейнер детерминированно переходит на текстовый стек.

## Воспроизводимость

Сиды зафиксированы (SEED=42, `random_state=42` во всех оценщиках). Внешние данные не
используются: единственный источник — `train_data.csv` из задачи. Модели — `gemma-4-E4B-it`
и `Qwen3.5-4B`, обе из рекомендованного списка, ≤4B.
